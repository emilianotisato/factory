The feature-docs board: `docs/project.toml`, one `state.toml` per feature

Usage: factory docs <COMMAND>

Commands:
  init       Scaffold docs/project.toml, docs/index.md, features/, ideas/, archive/
  new        Allocate the next PRD number and scaffold the feature
  slice      Add the next slice to a feature
  status     The board; with a feature, its state for resuming a run
  set        Write a feature's state.toml: `status=ready`, `slices.3.status=building`, `slices.3.lane=` (empty removes)
  retro      A feature's retros row in the metrics store; `--set score=4` sets its score
  check      Validate the board; exits 1 on any error
  doctor     Which framework version the repo is on, and what `check` would say
  log        The feature's append-only log.jsonl
  idea       The open ideas, one file each under docs/ideas/
  gate       The verify gate; `set <cmd>` declares it, `--inner` the fast subset
  preflight  Can a run start on this feature? Exits 0 pass, 1 refused, 2 asks
  ship       Mark a feature shipped once every slice is done
  archive    Move a feature whose slices are all done into docs/archive/
  lanes      The lanes; `set N --env K=V` writes the lane files
  renumber   Give a feature a new number, outside docs/archive/
  migrate    Move a v2 repo's docs to v3 in one uncommitted diff; `--dry` writes nothing
  hook       Install the pre-commit hook, or print it when core.hooksPath is set

Options:
  -h, --help  Print help
