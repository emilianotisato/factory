**Code-review fixes (2026-10-10).**
- The checkpoint's death cap reset on any answer naming no slice, so answering a refused merge or another checkpoint's block brought the once-only respawn back (Xd2). Its workers now count from the latest answer to one of that checkpoint's own blocks, in `events.jsonl` order (AD-20002, AD-20003).

**Slice**: After this slice the driver runs the full gate itself at every checkpoint the board declares: it drains the lanes, runs the declared command, caches the result against a hash of the code tree, and on red spawns a fix worker with the failing output, commits the fix and reruns.
