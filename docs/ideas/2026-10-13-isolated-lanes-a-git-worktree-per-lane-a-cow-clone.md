Root fix for unnamed files (PRD-001 run B; PRD-002 AD-305, AD-9901, 54 leftovers on slice 07): lanes share one tree (PRD-001 `prd.md:74`), so `Pathspec` misses every Bash edit (`git mv`, inline Python, `printf >`, rustfmt) and the checkpoint gates a dirty tree that HEAD does not match. Shape, brainstormed 2026-10-13: long-lived lane worktrees reset to the feature tip at each spawn; `cp --reflink` for `target/` (17G here, btrfs), `vendor/`, `node_modules/`, `.env`; commit is `git add -A` in the lane; the driver rebases onto the tip, a conflict spawns a merge worker, its failure is a BLOCK; the inner loop and every checkpoint run in a clean gate worktree of HEAD. Deletes `Pathspec`, `unnamed`, `leftovers`, baselines. Plus a `/lanes` skill that interviews a project into `lane-N.md` setups (per-lane DB, ports, Redis DB, queue prefix) and proves two lanes' suites run at once without colliding. Open: who writes slice status (lean: the worker reports, the driver writes the main board), the non-CoW fallback, disk growth.

**Added 2026-10-13, from the polish skill review.** Polish fixers are workers too: with `lanes: 1` the PRD-001 polish worker improvised its own worktree recipe (detached HEAD, own `CARGO_TARGET_DIR`, cherry-pick back, then one merge gate), and that merge gate caught a red no fixer's own green gate could see. The next worker will improvise a different recipe. So the isolation is deterministic and the CLI's, never prose in a skill: the driver spawns every fixer in a lane the same way it spawns a builder, and the merge gate after the fixers is the same gate-worktree-of-HEAD rule as a checkpoint. `polish` §5 drops its fixer rules once this ships. The `/lanes` skill exists nowhere yet; its only job is the interview that writes `lane-N.md`, the CLI runs them. **Open: what a lane file commits.** Here the four files are tracked and hold only a cargo target dir. In a Laravel repo one holds DB names, ports, a queue prefix, possibly a password. Lean: the committed recipe derives its values from the lane number (`app_lane_2`, port base plus N), so nothing secret needs storing, and a gitignored `lane-N.local.md` carries anything machine-specific.
