Source: [code.claude.com/docs/en/advisor](https://code.claude.com/docs/en/advisor). The worker's model consults a stronger advisor model at decision points. Claude decides when, with no cap and no way to force a call. Experimental, Anthropic API only. Why: a cost and quality lever per role. Run builders on Sonnet with an Opus advisor, or give fix and polish workers an advisor, and compare them as an A/B arm. Recon: (1) Set it per worker with `--advisor <model>` (hidden from `--help`) next to `--model` and `--effort` in `src/worker.rs`, or `advisorModel` in the worker's `<session>.settings.json`. A user-level `advisorModel` reaches workers too, so the driver should set it explicitly either way. (2) The advisor must rank at or above the worker's model: Opus 5.5 workers accept only Opus 5+ or Fable. The API drops a refused pairing silently, so check the stream to see that it ran. (3) Each call reads the whole transcript uncached, at the advisor's rates. Builders peak at 150–170k context, so one call can cost more than several turns. (4) It counts toward subscription limits, and Fable bills to usage credits. Check whether the stream's usage and `factory report` see advisor tokens; the API reports them separately. (5) Subagents inherit it. (6) It stays off when feature-flag fetching is off (`DISABLE_TELEMETRY`) or with `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`. The worker env scrub drops every `CLAUDE_*` outside `KEEP_CLAUDE_VARS`, so that switch must come through the settings file's `env` or a lane's env. Added 2026-10-12, not assessed yet.
