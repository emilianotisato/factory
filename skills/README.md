# Skills

Claude Code skills that ship with `factory`. Install one by linking its folder into your skills directory (a copy works too):

    ln -s "$(pwd)/skills/factory-deliver" ~/.claude/skills/factory-deliver

| skill | what it does |
|---|---|
| [`factory-deliver`](factory-deliver/SKILL.md) | the cockpit: start a run, wait on it, relay its questions, run the review interview |
